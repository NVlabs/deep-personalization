# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

To report a potential security vulnerability in this project, follow [NVIDIA's vulnerability reporting instructions](https://www.nvidia.com/en-us/security/report-vulnerability/).

Please include the repository name, affected version or commit, a description of the issue, steps to reproduce, and potential impact. Submit sensitive details only through the private reporting channels described in the linked instructions.
